# opi.k

Це головна папка для практичних робіт.

Структура:

- `practice23_formal_specification/` - практична робота №23: створення формальної специфікації програми.

Запуск тестів практичної №23 з головної папки:

```bash
python -m unittest discover -s practice23_formal_specification -v
```

Для наступних практичних можна створювати нові окремі папки поруч, наприклад:

```text
practice24_name/
practice25_name/
```

Так усі роботи будуть в одному Git-репозиторії.
